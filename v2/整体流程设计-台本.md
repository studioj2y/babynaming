# 星命观测局 · 宝宝起名视觉小说 —— 整体流程设计（台本）

> 原型版本：v2（`babyname/v2/index.html`）
> 本文档梳理从首屏到揭晓的完整用户体验架构：每一步的界面内容、引导语言、用户交互、背后逻辑、分支与表演/揭晓机制。

## 0. 产品基调与设计语言

**一句话定位**：以「星命观测局」为叙事壳，把起名这件复杂的事，包装成多位老师依次"同参"的一段仪式化体验；用户像在看一页会翻的漫画。

### 视觉与动效基调
| 维度 | 设计 | 实现 |
|---|---|---|
| 主题色 | 男孩=蓝 `#6f86c4`、女孩=粉 `#d4749a`、不限=紫 `#8a6fb0`；选择命格时切换 | `setTheme(gender)` 改 `--accent/--accent2/--glow` |
| 饱和度递进 | 首屏最素（12%）→ 逐场加深 → 汇总/占算 100% 满色 | `--sat` 随场景 `SAT` 表变化，`#bg/#stars/#top/#stage` 戴 `saturate` 滤镜 |
| 立绘层 | 立绘始终满色（不随饱和度递进变淡） | `#actorWrap`/`#ritualWrap` 在滤镜子树之外 |
| 首屏落叶 | 仅第一屏；三主题随机彩色叶；频率 +50%；间歇阵风 | `spawnLeaf` 仅在 `state.scene==="brand"`；`LEAF_INTERVAL≈1467ms`；`gustTick` 钟形阵风 |
| 氛围层 | 闪烁星点 / 随机漂移圆环 / 若隐若现光晕 / 缓慢变化的星座线 | `buildAmbient()` 注入 `#ambient` |
| 对话泡 | 漫画风圆角玻璃泡，带向上小箭头；无立绘场景（过目）去箭头 | `.bubble::before` 菱形箭头；`.bubble.no-arrow` 去除 |
| 入场动效 | 立绘淡入=淡出镜像（120% 缩入 + 下移）；表演改用 keyframes | `actorEnter/Leave`、`ritualEnter/Leave` |
| 打字机 | 台词逐字出现，打完才可点"继续" | `typeText()` |
| 登场门控 | 立绘登场完成后再出气泡/输入（避免气泡先于人物出现） | `state._actorReady` / `onEntered` 回调 |
| 转场 | 旧场景左滑出、新场景右滑入 | `transitionTo()`（`#scene.out/.in`） |

### 引导原则（贯穿全文）
- **每一步只问一件事**：分支 → 父/母姓 → 随姓方式 → 字数 → 命格，逐层递进。
- **老师各司其职**：引路用"观测小助理"，具体维度用对应专业老师（字源/语文/占星…）。
- **仪式感收尾**：多位老师"同参"表演 → 星师汇总 → 光球揭晓 → 候选名单。

## 1. 顶层流程图

```mermaid
flowchart TD
    brand[首屏 · 星命观测局] --> s01[引路]
    s01 --> s02{定分支}
    s02 -- 请星师荐名 / A --> s03a[引荐]
    s02 -- 观测已有候选名 / B --> s03b[引荐]
    s03a --> s04[父姓+母姓]
```

## 2. 分支逻辑

| | 分支 A · 请星师荐名 | 分支 B · 观测已有候选名 |
|---|---|---|
| 触发 | s02 选"请星师荐名"（`state.branch="A"`） | s02 选"观测已有候选名"（`state.branch="B"`） |
| 采集字段 | 父姓、母姓、名随何方、姓名字数、命格 | 候选名字、命格 |
| 采集步序 | s03a→s04→s05→s06→s07→s08 | s03b→b1→b2 |
| 汇总表行 | 父姓 / 母姓 / 名随何方 / 姓名字数 / 命格气韵 | 观测名字 / 命格气韵 |
| 后端接口 | `POST /api/generate` | `POST /api/analyze` |
| "改"回跳 | 父姓/母姓→s04、名随何方→s05、字数→s07、命格→s08 | 名字→b1、命格→b2 |

- **主题色何时定**：两条路径都在"命格"那一步（`s08` / `b2`）选择性别时调用 `setTheme(gender)`，并即时切换全局主题色（`theme:true`）。
- **共用表演/揭晓**：汇总确认后两条路径都进入 `s09` 占算表演，表演与揭晓逻辑完全相同。
- **状态重置**：点左上"星命观测局"调用 `goHome()`，清空 `state`（父/母姓、方式、字数、命格、名字、结果）、`branch` 回 `"A"`、清立绘、回首屏。

## 3. 逐场景台本

> 字段说明：**步骤条**=顶部右上角文字；**类型**=kind；**立绘**=出场角色；**引导语言**=用户看到的台词/界面文案；**交互**=用户动作；**逻辑**=背后代码；**→**=跳转。

### 首屏 brand
- 类型：`brand`　立绘：无（仅氛围）
- 界面：大标题「星命观测局」+ 副标「为小星主，参一名」+「进 入」按钮
- 引导语言：「星命观测局」/「为小星主，参一名」/ 按钮「进 入」
- 交互：点「进 入」
- 逻辑：`go("s01")`；`#leaves` 落叶仅在此屏出现
- → s01

### s01 · 引路
- 步骤条：引路　类型：`talk`　立绘：观测小助理（assistant-1）
- 引导语言（随机 1/2）：
  1. 「小星主将至，我是本局的观测助理，先替您引路。」
  2. 「星命观测局恭候多时，待小星主降世，自有佳名相迎。」
- 交互：点「继 续」
- 逻辑：`renderTalk` 打字机；`proceed(sc)` → `go(sc.next)`
- → s02

### s02 · 定分支
- 步骤条：定分支　类型：`branch`　立绘：观测小助理（assistant-2）
- 引导语言：「您是想请星师荐名，还是观测已有的候选名？」
- 交互：二选一（打字完成后按钮才可点）
  - 「请星师荐名」→ 设 `branch:"A"` → s03a
  - 「观测已有候选名」→ 设 `branch:"B"` → s03b
- 逻辑：`renderBranch`；选项 `set` 写入 `state` 再 `go(next)`
- → s03a / s03b

### s03a · 引荐（A 路径）
- 步骤条：引荐　类型：`talk`　立绘：观测小助理（assistant-4「说来惭愧」立绘）
- 引导语言：
  1. 「说来惭愧，我修行尚浅，还是请专门的老师为您细看。」
  2. 「取名乃大事，我这就引各位老师前来，请您安心。」
- 交互：点「继 续」→ s04

### s03b · 引荐（B 路径）
- 步骤条：引荐　类型：`talk`　立绘：观测小助理（assistant-5「已有名字」立绘）
- 引导语言：「也好，请写下那名字，我请语文老师为您细细观测。」
- 交互：点「继 续」→ b1

### s04 · 第一观测层 · 血脉（A）

- 界面：单输入框——「名字」(ph 如 林婉婷)；必填
- 交互：填名 → 点「继 续」
- 逻辑：`state.name` 写入；`require:["name"]`
- → b2

### b2 · 观测 · 命格（B）
- 步骤条：观测 · 命格　类型：`ask`　立绘：占星老师
- 引导语言：「小星主是男孩还是女孩？」
- 界面：分段选择——男孩 / 女孩 / 不限；提示「选择即定主题气韵」
- 交互：选命格 → 即时切换主题色 → 点「继 续」
- 逻辑：`state.gender` 写入；`setTheme(gender)`

### s_summary · 过目
- 步骤条：过目　类型：`summary`　立绘：无（星师立绘被隐藏，气泡无箭头）
- 引导语言：「请小星主过目所录，确认或改动。」
- 界面：汇总表（见 §2 分支对应行）+ 每行「改」按钮 + 「确认无误 · 起卦」
- 交互：
  - 点某行「改」→ `state.editReturn="s_summary"` 后跳回对应采集步（改完 `proceed` 回到本页）
  - 点「确认无误 · 起卦」→ 进入占算
- 逻辑：`renderSummary`；`proceed(sc)`（有 `editReturn` 则回 summary，否则 `go(s09)`）
- → s09

### s09 · 占算（表演）
- 步骤条：占算　类型：`ritual`　立绘：表演专用 `#ritualWrap` 满色层
- 内容：多位老师依次登场"同参"（详见《表演阶段明细清单》），最后星师总结
- 动效：星师总结后 7 枚光球从屏外螺旋旋入中心 → 炸开 + 全白屏 → 出现「揭 晓」按钮
- 交互：点「揭 晓」
- 逻辑：`enterRitual()` → 序列表演 → `reveal()`（光球动效）→ `doReveal()`
- → 揭晓结果

### 揭晓 · 结果页
- 步骤条：揭晓　类型：结果
- 动效：点「揭 晓」→ 9 枚光球从按钮中心飞出 → 围圆旋转约 1s → 炸开 → 白屏 → 候选名单
- 界面：星师荐名 N 枚；每枚：综合分 + 名字 + 推荐理由 + 六维条（五行/生肖/音律/字义/数理/气韵）+「展开细项分析」
- 交互：展开/收起细项；「重新起卦」（刷新重来）
- 逻辑：`renderResult()` 读 `state.result.names`
- 异常：若 API 失败显示「推算中断：…」+「重新起卦」

## 4. 表演阶段（占算）机制

**进入**：`s_summary` 确认后 `go("s09")` → `enterRitual()`。
- 隐藏 `#actorWrap`（提问立绘），显示 `#ritualWrap`（表演满色立绘层）；步骤条「占算」。
- 后台并行调用 `callAPI()` 取候选名（结果供揭晓页用）。

**序列构建**（每次进入重新随机）：
1. `perfSingles = shuffle(RITUAL 单人条目，排除星师)` → 按 `QTEACHERS`（提问阶段出场过的 assistant/ziyuan/yuwen/zhanxing/xingshi）**后置排序**：非提问老师优先、提问老师排后。
2. `pairs = shuffle(DUOS)`（双人合参）。
3. `SEQ = perfSingles.slice(0,-1).concat(pairs.slice(0,-1))`
   - 现行：单人出场 10 位（11 位中末位被裁掉）、双人出场 4 组（5 组中末组被裁），共 14 段 + 星师收尾。
   - **注意**：`zhanxing`（占星）属提问组（`QTEACHERS`），排序到末尾，再经 `slice(0,-1)` 裁掉末位一位 → 占星**约 2/3 概率出场、约 1/3 概率被裁**（与 ziyuan/yuwen 公平轮流），并非"不出场"。提问阶段它本来就以"命格"老师身份出现。若想让占星在表演阶段**必出场**，可把裁剪从"裁末位"改为"裁固定非占星位"或把占星移出 `QTEACHERS`。

**每段播放**：
- `setActors(keys)` 渲染立绘（单/双），登场即触发 `revealLine`（文字与立绘同频，延迟 80ms）。
- 单人：`.who`=师名，台词随机取 3 句之一。
- 双人：`.who`=「师A · 师B」，台词两段以 `<br>` 换行（前/后交叉互动）。
- 停留时长 `dwell = min(3740, round((1700 + 字数×22)×1.1))`（较旧版 +10%）。
- 星师收尾：`STAR_DWELL=2800ms`，随机 3 句总结之一。

**结算**：星师文字后 `reveal()` → 7 光球螺旋炸开白屏 → 原地出现「揭 晓」按钮。

## 5. 揭晓与结果页

- `doReveal(btn)`：防连点（`state._revealing`）；若有按钮则播 `playRevealOrbFx`（9 光球从按钮中心飞出→围圆旋转≈1s→炸开），随后白屏闪过 → `renderResult()`。
- `renderResult()`：
  - 清掉残留对话框与星师立绘，步骤条「揭晓」，背景半透明透出星野（类首页）。
  - 读 `state.result.names`：每枚名卡含 `total`(综合分)、`name`、`rank_reason`(推荐理由)、`dims`(六维 0–100)、`explain`(细项)。
  - 无候选名：提示「未得佳名…请放宽寓意或调整姓氏方式，再起一卦」+「重新起卦」。
  - 底部「重新起卦」（刷新）。

## 6. 返回首页 / 重置

- 左上「星命观测局」(`#top b`) 点击 → `goHome()`：清 `state`、branch 回 A、清立绘、回首屏 `brand`。
- 结果页/异常页「重新起卦」→ `location.reload()` 整页刷新。

## 7. 关键实现要点（给开发/接手者）

- **路由**：`go(id)` 读 `SCENES[id]`，按 `kind` 分发 `renderScene`；`s09` 走 `enterRitual`；`s10` 仅 loading 态遗留。
- **状态**：单一 `state` 对象（branch / 各采集字段 / result / 内部标志 `_revealed`/`_revealing`/`_rt`/`_actorReady`/`_onActor`/`editReturn`）。
- **分支**：`state.branch` 决定汇总表行与 API 接口；`proceed()` 处理"改后回汇总" vs 正常 next。
- **主题**：`setTheme(gender)` 改 CSS 变量；`SAT` 表控制每场饱和度。
- **表演引擎**：`enterRitual` 内闭包 `step()` 递归按时长推进；`QTEACHERS` 控制出场优先级；`rnd` 随机台词。
- **动画层**：`#bg/#stars/#top/#stage` 戴饱和度滤镜；`#actorWrap/#ritualWrap/#leaves/#ambient` 在滤镜外（满色）；`#orbFx/#revealOrbFx/#flash/#result` 为特效/结果覆盖层。
- **API**：`/api/generate`(A) / `/api/analyze`(B)；本地 `app.py` 有 mock 兜底，Vercel 走 `api/*.py`。
