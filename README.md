# 星命观测局

为准爸妈准备的取名参考工具，带一点「中二」仪式感。Web 版，部署到 Vercel 后任何设备浏览器即可访问，方便随时随地和家人一起挑名字。

> 名字是给孩子一生的礼物，本工具只作**参考与情绪陪伴**：玄学维度（五行 / 生肖 / 八字）是趣味加成，实用维度（读音 / 字义 / 谐音 / 字形）才是核心。最终请以您与家人的喜爱为准。

## 功能一览

**① 父母双姓 + 灵活字数**
- 分别输入「父亲姓氏」「母亲姓氏」（各 ≤2 字、汉字、非脏字）。
- 姓氏方式：**随父姓 / 随母姓 / 都要体现**（复姓 = 父姓 + 母姓，父先母后，且后续名会尽量呼应母姓部首）。
- 名字总字数：**双字名(2) / 三字名(3) / 四字名(4)**，严格按此生成；不兼容组合（如「都要体现」父+母=2 字时无法再取单名）前端自动置灰。

**② 四步轻量向导**
1. 血脉与字数（含生辰可选、自由期许可选）
2. 看重什么（拖动排序，决定各维度权重）
3. 寓意倾向（14 个意境标签多选，不选则全面考虑）
4. 结果（约 8 秒推算仪式 → 候选名单）

**③ 推算仪式（纯表演，结论已预计算）**
- 约 8 秒轮播「占星 / 八卦 / 语文 / 五行 / 术数 / 音律 / 字形 / 生肖 / 数理 / 意境 / 字源 / 典故」十二位老师的工作画面，以及老师之间的趣味互动短句（预置 30 句，随机展示，**不耗 AI**）。

**④ 直接观测候选名字**
- 首页输入已有心仪名字（如「林婉婷」），跳过所有步骤直接进仪式并得到**同格式**的多维分析。

**⑤ AI 能力（agnes-ai，优雅降级）**
- **整盘积极解读**：每张结果卡「✦ AI 详解」按钮，生成约 120 字温暖积极的解读。
- **自由期许映射**：首页填「希望孩子豁达开朗…」，AI 映射成寓意标签再去筛字。
- 重名率 / 网络撞梗 / 方言：缺外部数据源，先以**本地近似**呈现并明确标注「近似」，不消耗 AI（真实数据源后续接入）。

**⑥ 结果美观可分享**
- 每个名字含综合分徽章 + 7 维评分网格（五行 / 生肖 / 音律 / 谐音 / 字义 / 字形 / 气韵）。
- 点开任一名字看按维度的**积极解释**；每张可「📸 存此名」生成精美 PNG，也可底部「保存完整名单」一次性分享。

## 本地运行
```bash
pip install -r requirements.txt
python -m uvicorn app:app --port 8000
# 浏览器打开 http://127.0.0.1:8000/
```
> 注意：必须通过服务地址（如 `http://127.0.0.1:8000/`）打开，直接双击静态 `index.html` 没有后端，词库与推算都会失败。

## 部署到 Vercel
纯 Python 依赖（`fastapi` / `uvicorn` / `lunar_python`），无需编译，Vercel 可原生运行。
1. 将本目录推到 GitHub 仓库；
2. Vercel 导入该仓库即可（无需额外配置）；
3. 如需「✦ AI 详解 / 自由期许」功能，在 Vercel 环境变量中添加 `AGNES_API_KEY`（见下）。

- 静态首页：`index.html`
- 接口（`api/index.py`）：`/api/tags`、`/api/generate`、`/api/analyze`、`/api/ai_review`

### AI 密钥（环境变量）
`ai.py` 默认从环境变量 `AGNES_API_KEY` 读取；未设置时 AI 功能自动回退到本地模板，不影响主体流程。
- 本地：在运行环境中 `export AGNES_API_KEY=...`（仓库内请勿写入真实 key）。
- Vercel：项目 Settings → Environment Variables 添加 `AGNES_API_KEY`。
- 该 key 有日限额流（约 08:33 UTC+8 重置），请避免批量刷。

## 目录结构
- `core.py` 核心逻辑（八字五行、评分、积极话术、候选名分析、自由期许映射）
- `app.py` FastAPI 入口（含 `/api/generate`、`/api/analyze`、`/api/ai_review`）
- `api/index.py` Vercel Serverless 适配层
- `ai.py` agnes-ai 封装（整盘解读 + 标签映射，env key 优先，全量优雅降级）
- `data/gsc.csv` 通用规范汉字库（拼音/声调/笔画/部首/五行）
- `data/chars.json` 由 gsc.csv 预处理生成
- `data/good_chars.json` 精选好字池（约 218 字，含字义 / 寓意标签 / 性别倾向）
- `data/build_char_db.py` 字库预处理脚本
- `data/gen_chars.py` 用 AI 批量扩充好字池的构建期脚本（运行时无需 AI）

## 数据来源
- 汉字基础字段（拼音/声调/笔画/部首/五行）：[ben-hua/general_standard_chinese](https://github.com/ben-hua/general_standard_chinese)（8105 通用规范汉字）。
- 八字 / 生肖 / 五行：由 `lunar_python` 本地计算，无联网。
